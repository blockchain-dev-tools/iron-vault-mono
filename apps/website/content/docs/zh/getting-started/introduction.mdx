## 什么是 IRON Vault？

IRON Vault 将旧安卓手机改造为 BLE 硬件钱包。从 OKX Wallet、MetaMask 等宿主应用的角度看，它与 Ledger Nano X 完全一致——通过蓝牙使用相同的 GATT profile 和 APDU 协议进行通信。

## 核心功能

- 以太坊 HD 密钥派生（BIP-44，`m/44'/60'/0'/0/i`）
- Solana HD 密钥派生（SLIP-10 Ed25519，`m/44'/501'/0'/0'`）
- BLE 外设模式，完整复刻 Ledger GATT UUID
- 交易签名时需在设备上手动确认
- 助记词备份与 PIN 保护
