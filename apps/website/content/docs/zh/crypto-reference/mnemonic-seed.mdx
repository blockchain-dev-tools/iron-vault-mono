# 助记词与种子

如果 HD 钱包是一棵密钥树，**种子** 就是它的根。而如果种子是 64 字节的随机数据（根本没法可靠地抄写下来），**助记词短语** 就是它的人类友好编码。

这就是 BIP39：将对原始熵（随机数据）编码成你可以在纸上手写的单词序列的标准。

---

## 熵：一切的起点

每个钱包都始于随机性。BIP39 支持两种安全级别：

| 单词数 | 熵位数 | 安全等级 |
|---|---|---|
| 12 个词 | 128 位 | 标准级别（对大多数使用场景足够） |
| 24 个词 | 256 位 | 最高级别（为未来量子计算预留） |

128 位熵意味着有 2¹²⁸ 种可能的钱包——比宇宙中的原子数量还多。24 词短语在实用层面并没有"更安全"；两者都不可通过暴力破解实现。

---

## 从熵到单词

BIP39 通过三个步骤将熵转换为单词：

```
熵（128 位）
    → SHA-256 → 取前 4 位作为校验和
    → 将校验和附加到熵末尾（共 132 位）
    → 分成 11 位一组（共 12 组）
    → 每组 = 2048 词单词表的索引
    → 结果：12 个单词
```

**校验和**（12 词为 4 位，24 词为 8 位）意味着从词表中随机选出的单词几乎肯定是 **无效的**——它无法通过校验和检查。这能在你恢复钱包时捕获抄写错误。

词表本身包含 2048 个精心挑选的单词，具有以下特点：

- **不易混淆**——没有发音相近的单词
- **较短**——平均 4–7 个字符
- **意义明确**——没有同音词

BIP39 定义了 10 种语言的词表，但英语是通用标准。大多数钱包（包括 Iron Vault）默认使用英语。

---

## 密码短语（Passphrase）："第 25 个词"

BIP39 包含一个可选的 **密码短语**——一个修改种子的密码：

```
种子 = PBKDF2(助记词 + 密码短语)
```

使用不同的密码短语，从相同的 12/24 个单词会生成完全不同的地址集合。这意味着：

- **可否认性**——给攻击者一个低价值的密码短语，隐藏真正的那一个
- **额外安全**——即使有人找到了你写下的助记词，没有密码短语也无法访问钱包
- **隐藏钱包**——同一个助记词搭配不同密码短语可创建独立身份

**警告**：密码短语 **不会** 存储在钱包中。丢失密码短语意味着资金永久丢失——即使有正确的助记词也无法恢复。

---

## 从助记词到种子

单词本身不是种子。种子是通过 **PBKDF2-SHA512** 从助记词（和可选的密码短语）派生出来的——这是一个刻意缓慢的密钥派生函数：

```
种子 = PBKDF2(
    密码 = 助记词（NFKD 标准化的 UTF-8 编码）
    盐   = "mnemonic" + 密码短语（同样 NFKD 标准化）
    迭代次数 = 2048
    输出长度 = 512 位（64 字节）
)
```

2048 次迭代使得暴力破解尝试在计算上代价高昂。结果始终是 64 字节，无论你从 12 词还是 24 词开始。

这个种子随后成为 **BIP32 密钥树的根节点**——钱包中每个私钥、公钥和地址的源头。

---

## 关系总结

```
熵（128–256 位）
    │
    ▼ BIP39
助记词短语（12–24 个单词）
    │
    ▼ PBKDF2（2048 轮迭代）
种子（64 字节）
    │
    ▼ BIP32
主私钥 + 链码
    │
    ▼ 子密钥派生（CKD）
账户密钥 → 地址
```

钱包中的一切都可以追溯到最初的熵。备份助记词（以及密码短语，如果使用了的话），就备份了一切。
