# 派生路径

从一个单一种子出发，HD 钱包可以生成数十亿个密钥。如果没有标准化的组织方式，不同厂商的钱包就会从同一个种子产生不同的地址——使得恢复变得不可能。

派生路径通过定义钱包应为哪个区块链使用密钥树的 **哪个分支** 来解决这个问题。

---

## 路径格式

派生路径看起来像一个带撇号的文件系统路径：

```
m / 44' / 60' / 0' / 0 / 0
```

| 段 | 含义 | 示例 |
|---|---|---|
| `m` | 主节点（根） | 始终存在 |
| `purpose'` | BIP 标准 | `44'` = BIP44，`84'` = BIP84 |
| `coin_type'` | 区块链标识 | `60'` = 以太坊，`501'` = Solana |
| `account'` | 用户账户索引 | `0'` = 第一个账户 |
| `change` | 外部（0）或内部（1） | `0` = 收款地址 |
| `index` | 地址序号 | `0` = 第一个地址 |

撇号（`'`）标记 **硬化** 派生步骤，使用私钥（而非公钥）进行派生。这创建了一个安全边界。

---

## BIP44：多账户标准

[BIP44](https://github.com/bitcoin/bips/blob/master/bip-0044.mediawiki) 定义了最广泛使用的路径结构：

```
m / purpose' / coin_type' / account' / change / address_index
```

### 常见币种类型

每个区块链都有一个注册的币种类型编号：

| 链 | 币种类型 | 路径前缀 |
|---|---|---|
| 比特币 | `0` | `m/44'/0'/...` |
| 以太坊 | `60` | `m/44'/60'/...` |
| Solana | `501` | `m/44'/501'/...` |
| 波场 | `195` | `m/44'/195'/...` |
| Sui | `784` | `m/44'/784'/...` |

这些编号在 [SLIP44](https://github.com/satoshilabs/slips/blob/master/slip-0044.md) 标准中注册。

---

## 为什么有不同的 BIP 编号

你会看到以 `44'`、`49'`、`84'` 和 `86'` 开头的路径。这些不是不同的钱包——它们是比特币不同的 **地址格式**：

| 用途 | 标准 | 地址格式 | 示例路径 |
|---|---|---|---|
| `44'` | BIP44 | 传统地址（以 `1` 开头） | `m/44'/0'/0'/0/0` |
| `49'` | BIP49 | 隔离见证兼容（以 `3` 开头） | `m/49'/0'/0'/0/0` |
| `84'` | BIP84 | 原生隔离见证（以 `bc1` 开头） | `m/84'/0'/0'/0/0` |
| `86'` | BIP86 | Taproot（以 `bc1p` 开头） | `m/86'/0'/0'/0/0` |

对于以太坊和 Solana 等只有一种地址格式的区块链，用途始终为 `44'`。

---

## 找零：外部与内部

`change` 层级区分了你给别人使用的地址（外部）和交易后的找零地址（内部）：

- **`0`** —— 外部链：你分享给他人以接收资金的地址
- **`1`** —— 内部链：交易后剩余资金所在的找零地址

对于以太坊和 Solana（使用账户模型而非 UTXO），这个区分并不适用，但路径结构为了兼容性仍然包含它。

---

## 账户发现

当你用助记词恢复钱包时，它如何知道哪些地址是你用过的？它不可能扫描数十亿个地址。相反，钱包使用一种称为 **间隔限制（gap limit）** 的技术：

1. 从 `index = 0` 开始
2. 派生地址并在区块链上检查交易记录
3. 如果找到交易，移动到 `index + 1` 并重复
4. 如果连续找到 **20 个未使用的地址**（间隔限制），则停止

这通常能在前几个索引内找到所有使用过的地址。Iron Vault 为每个支持的链预派生第一个账户，无需扫描区块链。

## Iron Vault 默认路径

Iron Vault 使用以下默认派生路径：

| 链 | 默认路径 |
|---|---|
| 以太坊 | `m/44'/60'/0'/0/0` |
| Solana | `m/44'/501'/0'/0'` |
| 比特币（隔离见证） | `m/84'/0'/0'/0/0` |
| 波场 | `m/44'/195'/0'/0/0` |
| Sui | `m/44'/784'/0'/0'/0'` |

你可以使用 [BIP39 工具](/docs/crypto-reference/bip39-tool) 添加更多路径和自定义派生。

---

## 路径兼容性

相同的助记词在不同的钱包中应该产生相同的地址——但前提是所有钱包使用相同的派生路径。实际上：

- **MetaMask** 对以太坊使用 `m/44'/60'/0'/0/0`
- **Ledger Live** 使用相同路径但会发现多个账户
- **OKX Wallet** 和 **Phantom** 对其相应链遵循相同的 BIP44 路径

这就是 Iron Vault 与现有钱包兼容的原因：它严格按照相同的标准派生密钥。你在 Iron Vault 中使用的助记词将在 MetaMask 中产生相同的以太坊地址。
